# data/raw/

[Layer 1 - Data & Models] Untouched dataset downloads. Nothing in this
folder is committed (see root `.gitignore`) except this file - it is
regenerated by `../scripts/` on any machine that needs it.

Per MIP Section 3.1:

- **Primary: IO-VNBD** (Onyekpe et al., Coventry University). Download
  both the Synchronised and Unsynchronised splits, both the V (vehicle-
  extracted ground truth) and S (smartphone-recorded) folders.
- **Secondary (collected by the team before the finale):** short
  GNSS-available loops on at least one two-wheeler, one auto-rickshaw,
  and one car, each 10-20 minutes, raw phone IMU + GNSS at the phone's
  native max rate. IO-VNBD has no Indian two-wheeler data - this is
  what seeds the road-signature packs (Section 4.4) and the
  calibration adapter (Section 4.5).

Whoever runs the download script should record exactly which IO-VNBD
splits/version were pulled and when, so a stale local copy doesn't
silently diverge from what teammates have.
